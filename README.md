# SnapRec

Free screen recorder & screenshot tool for Windows.

## Download
Get the latest installer from the Releases page — run SnapRec_Setup.exe and you're set. No admin rights needed.

## Features
- Screenshot with markup tools (pen, arrow, shapes, text)
- Screen recording — full screen or a chosen region
- Live Draw: draw on the screen while recording (F8)
- Cursor ring, click effects and highlight disc
- Built to run well on modest PCs
